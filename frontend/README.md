# FPT Exam Support Frontend

Giao diện React/Vite cho hệ thống chatbot hỗ trợ giám thị và cán bộ coi thi.

## Yêu cầu

- Node.js 20 trở lên
- npm

## Cài đặt và chạy

```bash
cp .env.example .env
npm install
npm run dev
```

Frontend mặc định chạy tại `http://localhost:8080`. Cấu hình địa chỉ backend bằng `VITE_API_URL`.

## Kiểm tra

```bash
npm run lint
npm run test
npm run build
```
